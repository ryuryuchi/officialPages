# アセテートテープの特徴と選び方

## 概要

一般に「アセテートテープ」と呼ばれるアセテートクロス粘着テープについて、材質、主な用途、性能、選定時の注意点を調べた。

## 結論

アセテートテープは、アセテート繊維の布（アセテートクロス）を基材にした粘着テープで、柔軟性と凹凸面への追従性を生かして、トランス・コイルの巻き止め、電線やワイヤーハーネスの結束・保護などに使われる。

電気絶縁用途では、一般の布テープではなく、用途に合う絶縁性能・耐熱性能・難燃認証を持つ製品を選ぶ必要がある。絶縁破壊電圧、粘着力、厚さ、色、難燃性などの数値は製品ごとに異なるため、商品名だけで判断せず、メーカーの仕様表と使用条件を確認する。

## 詳細

### 材質と特徴

- 基材はアセテートクロスで、粘着剤にはアクリル系やゴム系など製品ごとの違いがある。
- 布基材のため柔軟で、電線束やコイルのような曲面・凹凸面になじみやすい。
- 手で切断しやすい製品が多く、配線作業や巻き止めの作業性がよい。
- 電気絶縁用として設計された製品には、A種電気絶縁への適合をうたうものや、難燃規格に適合するものがある。
- 「アセテート」という基材名だけでは、耐熱温度、絶縁破壊電圧、難燃性、粘着力までは決まらない。

### 主な用途

| 用途 | 使い方 |
| --- | --- |
| トランス・コイル | 巻き止め、層間・外装の絶縁 |
| ワイヤーハーネス | 電線束の結束、保護、異音や擦れの抑制 |
| 電子機器 | 部品や配線の固定・絶縁 |
| モーター・電装品 | 巻線や部材の保護。ただし必要な規格・温度条件を満たす製品に限る |

### 製品仕様の見方

製品例では、テープ全体の厚さが約0.21～0.25 mm、絶縁破壊電圧が約1.5～3.7 kVの範囲にあるものが確認できる。ただし、これはメーカーや型番が異なる製品を含む代表例であり、共通規格値ではない。

選定時は次の順に確認するとよい。

1. **用途**: 結束だけか、電気絶縁・巻線固定まで必要かを決める。
2. **温度**: 連続使用温度と、短時間のピーク温度が機器の条件を満たすか確認する。
3. **電気性能**: 必要な絶縁破壊電圧、絶縁区分、使用電圧に適合するか確認する。
4. **難燃性**: 火炎にさらされる可能性がある場合は、UL 510などの認証・等級を確認する。
5. **粘着特性**: 粘着力、保持力、巻き戻しやすさ、貼り付ける材質との相性を確認する。
6. **環境条件**: 湿気、油、薬品、振動、屋外使用、保管温度を確認する。

### 使用上の注意

- 交流電源や高電圧部の補修に、仕様不明のアセテートテープを代用しない。テープの絶縁破壊電圧は、厚さ・試験条件・製品構造で変わる。
- 電線の結束用と、絶縁設計の一部として使う製品は目的が異なる。必要な規格表示がない製品を、規格適合品として扱わない。
- メーカーの仕様値は試験方法に基づく参考値の場合がある。寺岡製作所も、使用前に実際の用途でテストするよう案内している。
- 被着体のほこり、油、水分を除去してから貼り付ける。保管時は直射日光、高温多湿を避ける。
- 粘着テープは人体に貼る用途の製品ではない。皮膚保護や医療用途には、用途表示のある専用品を使う。

### ビニール絶縁テープとの使い分け

アセテートテープは、布基材の柔軟性、手切れ性、巻き止め・結束の作業性を重視する用途に向く。一方、屋外での耐候性、防水性、伸びを利用した密着などが必要な場合は、ビニール系など別基材の電気絶縁テープが適することがある。最終的には、用途、温度、電圧、環境に対する製品仕様で選ぶ。
