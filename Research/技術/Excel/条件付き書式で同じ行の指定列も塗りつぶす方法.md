# Excelの条件付き書式で同じ行の指定列も塗りつぶす方法

## 概要

Excelの条件付き書式で、ある列の値を判定し、条件に合う行の指定した列にも同じ塗りつぶしを適用する方法を整理する。

## 結論

塗りつぶしたい範囲全体へ、数式を使う条件付き書式を設定する。判定に使う列だけを`$`で固定し、行番号は固定しない。

たとえば、C列が「完了」の行についてA列からF列まで塗りつぶす場合は、適用先を`=$A$2:$F$100`、条件式を次のようにする。

```excel
=$C2="完了"
```

`$C`は判定列をC列に固定し、`2`は各行に合わせて変化させる指定である。

## 詳細

### 基本手順

例として、C列が「完了」の行についてA列からF列まで塗りつぶす。

1. 見出しを除く対象範囲`A2:F100`を選択する。
2. `ホーム`タブの`条件付き書式`から`新しいルール`を選択する。
3. `数式を使用して、書式設定するセルを決定`を選択する。
4. 次の数式を入力する。

   ```excel
   =$C2="完了"
   ```

5. `書式`を選択し、`塗りつぶし`タブで色を指定する。
6. `OK`でルールを確定する。
7. `条件付き書式`の`ルールの管理`で、適用先が次の範囲になっていることを確認する。

   ```excel
   =$A$2:$F$100
   ```

この設定では、C2が「完了」ならA2:F2、C3が「完了」ならA3:F3というように、各行が個別に判定される。

### 離れた指定列だけを塗りつぶす場合

たとえば、C列を判定し、同じ行のA列とF列だけを塗りつぶす場合も、条件式は同じである。

```excel
=$C2="完了"
```

適用先は、`Ctrl`キーを押しながらA列とF列の対象範囲を選択するか、`ルールの管理`で複数範囲を指定する。

```excel
=$A$2:$A$100,$F$2:$F$100
```

Excelの環境によって複数範囲の区切り記号が異なる場合や、複数範囲を一度に設定しにくい場合は、A列用とF列用に同じ条件式のルールを1件ずつ作成する。

### 数式の参照方法

| 書き方 | 固定される部分 | この用途での意味 |
| --- | --- | --- |
| `$C2` | C列 | 各行のC列を判定する。今回の基本形 |
| `$C$2` | C列と2行目 | すべての行でC2だけを判定する |
| `C2` | なし | 適用先の列に応じて判定列も横へずれる |
| `C$2` | 2行目 | 判定する行を2行目に固定し、列は横へずれる |

同じ行の複数列を塗りつぶす場合、通常は`$C2`のように、列だけを固定する複合参照を使う。

### 条件式の例

#### 数値が基準以上

B列が100以上の行を塗りつぶす。

```excel
=$B2>=100
```

#### 空白以外

D列に何か入力されている行を塗りつぶす。

```excel
=$D2<>""
```

#### 複数条件

B列が100以上、かつC列が「完了」の行を塗りつぶす。

```excel
=AND($B2>=100,$C2="完了")
```

### 注意点

- 数式の行番号は、適用範囲の先頭行に合わせる。適用先が`A5:F100`なら、条件式も`=$C5="完了"`から始める。
- 判定列の`$`を外すと、塗りつぶす列ごとに参照先が横へずれるため、意図しない結果になりやすい。
- 見出し行を適用範囲に含めない。含める場合は、数式の行番号も見出し行に合わせる必要がある。
- 既存の条件付き書式と競合する場合は、`ルールの管理`で適用先、優先順位、`条件を満たす場合は停止`の設定を確認する。
