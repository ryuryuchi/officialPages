# Excelでクリックして画像を挿入するボタンの作り方

## 概要

Excelのワークシート上にボタンを置き、クリックするとファイル選択画面が開いて、選んだ画像を指定セルの範囲内へ挿入する方法を整理する。マクロを使わない標準機能と、Office Scriptsを使う場合の制約も比較する。

## 結論

Windows版またはMac版のデスクトップExcelで、ローカルPCから画像を選ぶ操作までボタン1つにまとめるなら、`フォームコントロールのボタン + VBA`が適している。

- `Application.GetOpenFilename`で画像ファイルの選択画面を表示する。
- `Shapes.AddPicture`で選択した画像をワークシートへ埋め込む。
- 画像をセルの範囲内に縦横比を保って縮小し、中央へ配置する。
- ブックはマクロ有効ブック（`.xlsm`）で保存する。

マクロを使えない環境では、対応版Excelの`挿入 > 画像 > セルに配置`を手動で
使う方法が簡単である。ただし、ワークシート上の独自ボタンをクリックしてローカル
画像を選択する一連の操作にはならない。

Office Scriptsはワークシート上に実行ボタンを置けるが、Microsoftの公式サンプルではローカル画像ファイルを扱えないと明記されている。そのため、今回の「クリックしてPC内の画像を選ぶ」用途にはVBAを推奨する。

## 詳細

### 方法の比較

| 方法 | 独自ボタン | ローカル画像の選択画面 | Excel for the web | 主な用途 |
| --- | --- | --- | --- | --- |
| フォームボタン + VBA | 対応 | 対応 | 非対応 | デスクトップExcelで今回の要件を実現する |
| `挿入 > 画像 > セルに配置` | 非対応 | 対応 | 対応する環境あり | マクロなしで手動挿入する |
| Office Scriptsのボタン | 対応 | 非対応 | 対応 | URL上の画像や既存画像を自動処理する |
| `IMAGE`関数 | 非対応 | 非対応 | 対応 | HTTPSの画像URLをセル内に表示する |

VBAマクロはExcel for WindowsとExcel for Macでは利用できるが、Excel for the webとモバイル版では実行できない。Office ScriptsはWeb、Windows、Macで利用できるが、利用可能なMicrosoft 365ライセンスや組織設定の影響を受ける。

### 完成時の動作

次の例では、ワークシート上のボタンを押すと画像選択画面が開く。画像を選ぶと`B2`へ挿入され、セルより大きい場合だけ縦横比を保って縮小される。同じボタンでもう一度選ぶと、前の画像を新しい画像へ置き換える。

セル`B2`の行の高さと列幅をあらかじめ画像表示用の大きさに調整しておく。

### 作成手順

1. 対象ブックを`Excel マクロ有効ブック（*.xlsm）`で保存する。
2. `開発`タブが表示されていない場合は、Excelのオプションでリボンの`開発`を有効にする。
3. `Alt + F11`を押してVisual Basic Editorを開く。
4. `挿入 > 標準モジュール`を選択する。
5. 次のコードを貼り付ける。

```vb
Option Explicit

Public Sub InsertImageToB2()
    Const TARGET_ADDRESS As String = "B2"
    Const IMAGE_NAME As String = "InsertedImage_B2"

    Dim filePath As Variant
    Dim target As Range
    Dim picture As Shape
    Dim existingShape As Shape

    filePath = Application.GetOpenFilename( _
        FileFilter:="画像ファイル (*.jpg;*.jpeg;*.png;*.gif;*.bmp),*.jpg;*.jpeg;*.png;*.gif;*.bmp", _
        FilterIndex:=1, _
        Title:="挿入する画像を選択してください", _
        MultiSelect:=False)

    If VarType(filePath) = vbBoolean Then Exit Sub

    Set target = ActiveSheet.Range(TARGET_ADDRESS)

    For Each existingShape In ActiveSheet.Shapes
        If existingShape.Name = IMAGE_NAME Then
            existingShape.Delete
            Exit For
        End If
    Next existingShape

    Set picture = ActiveSheet.Shapes.AddPicture( _
        Filename:=CStr(filePath), _
        LinkToFile:=msoFalse, _
        SaveWithDocument:=msoTrue, _
        Left:=target.Left, _
        Top:=target.Top, _
        Width:=-1, _
        Height:=-1)

    With picture
        .Name = IMAGE_NAME
        .LockAspectRatio = msoTrue

        If .Width > target.Width Then .Width = target.Width
        If .Height > target.Height Then .Height = target.Height

        .Left = target.Left + (target.Width - .Width) / 2
        .Top = target.Top + (target.Height - .Height) / 2
        .Placement = xlMoveAndSize
    End With
End Sub
```

6. Visual Basic Editorを閉じる。
7. Excelで`開発 > 挿入 > フォームコントロール > ボタン`を選択し、シート上へボタンを配置する。
8. 表示された`マクロの登録`画面で`InsertImageToB2`を選択する。
9. ボタンの表示文字を`画像を選択`などへ変更する。
10. ボタンをクリックし、選択した画像が`B2`の範囲内へ挿入されることを確認する。

フォームコントロールの代わりに、`挿入 > 図形`で作成した図形へ`マクロの登録`を行っても、ボタンのように使用できる。

### 挿入先を変更する

挿入先を`D5`へ変える場合は、コード先頭の定数だけを変更する。

```vb
Const TARGET_ADDRESS As String = "D5"
Const IMAGE_NAME As String = "InsertedImage_D5"
```

複数の挿入場所を用意する場合は、マクロを場所ごとに複製するより、名前付き範囲やボタン名から挿入先を判定する共通マクロにした方が管理しやすい。ただし、配置規則はブックの設計によって異なるため、実際の表に合わせて決める必要がある。

### コードの要点

- `GetOpenFilename`は標準のファイル選択画面を表示し、ファイル自体は開かずにパスを返す。
- キャンセル時は`False`が返るため、何も変更せず終了する。
- `LinkToFile:=msoFalse`と`SaveWithDocument:=msoTrue`により、元画像へのリンクではなく画像のコピーをブックへ保存する。
- `LockAspectRatio = msoTrue`により、画像を縮小しても縦横比を維持する。
- `Placement = xlMoveAndSize`により、行の高さや列幅の変更に合わせて画像も移動、サイズ変更される。
- 同名の画像を先に削除するため、再選択時に画像が重なり続けない。

### 注意点

#### セキュリティ

マクロは信頼できるブックだけで有効にする。組織のポリシーによってはVBAマクロが無効化されていたり、署名済みマクロだけが許可されていたりする。その場合は管理者への確認が必要である。

#### 対応環境

- VBAはデスクトップ版のExcel for WindowsとExcel for Mac向けである。
- Excel for the webではVBAマクロを実行できない。
- ActiveXコントロールではなくフォームコントロールまたは図形を使う方が、Windows固有機能への依存を減らせる。
- `GetOpenFilename`の`ButtonText`引数はMac専用だが、上記コードでは使用していない。

#### ファイル形式と容量

- 上記のファイル選択フィルターはJPG、JPEG、PNG、GIF、BMPを対象にしている。
- 画像をブックへ埋め込むため、画像の枚数や解像度が増えると`.xlsm`ファイルも大きくなる。
- GIFは挿入できても、用途やExcelの機能によってアニメーション表示は期待できない。

### マクロを使わない場合

対応版Excelでは、セルを選択して`挿入 > 画像 > セルに配置`から画像を挿入できる。
貼り付け済みの浮動画像は、画像を選択して`図の形式 > セルに配置`、または右クリック
メニューからセル内画像へ変換できる。複数画像を同時に選ぶと、アクティブセルから
下方向の連続セルへ挿入され、既存のセル値は上書きされるため注意する。

URL上の画像でよければ、`IMAGE`関数も候補になる。

```excel
=IMAGE("https://example.com/image.png", "商品画像")
```

ただし、`IMAGE`関数はローカルPCのファイル選択ボタンではなく、対応するHTTPS URL
から画像を表示する機能である。認証が必要なURLやリダイレクトされるURLは表示
できない。

### Office Scriptsを採用しない理由

Office Scriptsには、関連付けたスクリプトをワークシート上のボタンから実行する機能がある。一方、Microsoftの画像追加サンプルは、URLから画像を取得してBase64へ変換する方法を示し、ローカル画像ファイルには対応していないと明記している。

したがって、画像がOneDrive、SharePoint、Webサーバーなどにあり、URLや別の処理からデータを渡せる場合はOffice Scriptsも候補になるが、利用者がその場でPC内の画像を選ぶ今回の要件には合わない。
