マウスから離れやすいVS Codeキーボードショートカット

概要

Windows版VS Codeで、カーソル移動、選択、編集、検索、表示切替をマウスに 頼らず行うための既定ショートカットを整理する。

結論

既に使っているCtrl+D、Alt+Up / Alt+Down、Ctrl+Pに加えて、まず Ctrl+Shift+P（コマンドパレット）、Ctrl+Backtick（統合ターミナル）、 F8（次の問題）、Alt+Left / Alt+Right（移動履歴）、Ctrl+K Ctrl+S （ショートカット設定）を覚えると、編集以外の操作でもマウスを使う頻度を 減らせる。

既定キーは拡張機能、ユーザー設定、キーボード配列、OSやドライバーとの競合で 変わり得る。実際に割り当てられたキーはCtrl+K Ctrl+Sで確認し、競合時は 同画面のShow Same Keybindingsまたは Developer: Toggle Keyboard Shortcuts Troubleshootingで確認する。

詳細

追加で便利な既定ショートカット

分類 ショートカット 操作 使いどころ
コマンド Ctrl+Shift+P / F1 コマンドパレットを開く 名前を覚えていない機能も、機能名で実行する。
ショートカット Ctrl+K Ctrl+S Keyboard Shortcutsを開く キーの検索、変更、競合確認を行う。2回連続で押すコード（chord）である。
保存 Ctrl+S 保存 変更を明示的に保存する。
ファイル Ctrl+N 新規ファイル 作業用の未保存ファイルを開く。
エディター Ctrl+W 現在のエディターを閉じる 読み終えたタブを閉じる。
エディター Ctrl+\ エディターを分割 定義やテストを横に並べて参照する。
エディター Ctrl+1 / Ctrl+2 / Ctrl+3 指定したエディターグループへ移動 分割したペインをキーボードで行き来する。
表示 Ctrl+B 主サイドバーを表示・非表示 コード領域を一時的に広くする。
パネル Ctrl+J 下部パネルを表示・非表示 ターミナル、Problems、Outputの表示を切り替える。
ターミナル Ctrl+Backtick 統合ターミナルを表示・非表示 編集とコマンド実行を往復する。Backtickは`キーを指し、位置はキーボード配列で確認する。
問題 Ctrl+Shift+M Problemsビューを開く エラーと警告を一覧する。
問題 F8 / Shift+F8 次／前の問題へ移動 エラーを順に修正する。
ナビゲーション Alt+Left / Alt+Right 前／次の移動位置へ戻る／進む 定義ジャンプや検索結果をたどった後に戻る。
定義 F12 定義へ移動 シンボルの実装を開く。
定義 Alt+F12 定義をプレビュー 現在の位置を保ったまま定義を確認する。
シンボル F2 シンボル名を変更 対応言語では文字列置換ではなく意味を考慮して名前を変更する。
検索 Ctrl+H 現在のファイルで置換 置換前に差分を確認する。
検索 Alt+L 選択範囲内の検索を切替 長いファイルの選択部分だけを検索する。
検索 Ctrl+Shift+J 全体検索の詳細を表示・非表示 含める／除外するファイルパターンを指定する。
選択 Ctrl+K Ctrl+D 次の一致をスキップ Ctrl+Dで不要な一致を選んでしまいそうな場合に使う。
編集 Ctrl+/ 行コメントを切替 コードを一時的に無効化したり、コメントを付けたりする。
整形 Shift+Alt+F ドキュメントを整形 言語ごとのフォーマッターが利用できる場合に使う。
表示 Ctrl+K Z Zen Modeを開始 集中時にUIを最小化する。終了はEscを2回押す。

習得の順序

  1. Ctrl+Shift+Pを入口にし、マウスでメニューを探す代わりにコマンド名を検索する。
  2. F12、Alt+Left、Alt+Rightでコードをたどり、戻る操作までを一組で使う。
  3. Ctrl+Backtickでターミナルを出し、Ctrl+Jで必要に応じてパネル全体を隠す。
  4. Ctrl+Shift+MとF8で問題を順番に確認・修正する。
  5. 使用頻度が高い未割り当て操作だけをCtrl+K Ctrl+Sから追加する。

カスタマイズ時の注意

事実: VS CodeではKeyboard Shortcutsエディターから、コマンドまたはキーを 検索し、既定キーの変更、削除、リセットができる。ユーザー定義は keybindings.jsonにも保存でき、when条件を使って適用場面を限定できる。

判断: 最初から多くの既定キーを変更するより、既定キーで困る操作だけを 変更する方が、ドキュメント、他の環境、ペア作業とのずれを抑えやすい。 Ctrl+Alt+Up / Ctrl+Alt+Downが効かない場合は、グラフィックスドライバー等との 競合を先に確認する。
