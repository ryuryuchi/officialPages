# 二乗などの上付き数字をWindowsで入力する方法

## 概要

Windowsで「x²」「x³」のような上付き数字を入力する方法を、入力先が通常のテキスト欄かMicrosoft Wordかに分けて整理する。

## 結論

通常のテキスト欄では、まず次の文字をコピーして使う方法が確実である。

```text
⁰ ¹ ² ³ ⁴ ⁵ ⁶ ⁷ ⁸ ⁹
```

Windows標準機能を使う場合は、入力中に `Windows` + `.`（ピリオド）で記号パネルを開くか、「文字コード表」を起動して文字をコピーする。Microsoft Wordでは、`00B2` と入力して `Alt` + `X` を押すと `²` に変換できる。また、任意の数字や文字を上付きにする場合は、対象を選択して `Ctrl` + `Shift` + `+` を押す。

## 詳細

### 1. すぐ使う場合は上付き数字をコピーする

二乗・三乗でよく使う文字は次のとおりである。

| 用途 | 文字 |
| --- | --- |
| 上付き0〜9 | `⁰¹²³⁴⁵⁶⁷⁸⁹` |
| 二乗 | `²` |
| 三乗 | `³` |
| 上付きの括弧・符号 | `⁽⁾⁺⁻⁼` |

これは書式ではなく、Unicodeの別の文字である。そのため、メモ帳、ブラウザー、チャットなど、文字を入力できる場所で使いやすい。一方、すべての文字に上付き版が用意されているわけではなく、フォントによって表示できない場合もある。

### 2. Windowsの記号パネルを使う

1. 文字を入力できる場所にカーソルを置く。
2. `Windows` + `.`（ピリオド）を押す。`Windows` + `;`（セミコロン）でも開ける。
3. 記号の一覧から目的の文字を選ぶ。

Windows 11の絵文字パネルには、絵文字だけでなく記号も含まれている。検索欄で目的の記号を探せるが、上付き数字が常に見つかるとは限らない。その場合は文字コード表か、既存の文字のコピーが確実である。

### 3. 「文字コード表」で探してコピーする

1. スタートメニューで「文字コード表」または `charmap` を検索して起動する。
2. フォントを選ぶ。通常は既定のフォントのままでよい。
3. 一覧から文字を選び、「選択」→「コピー」を押す。
4. 入力先で `Ctrl` + `V` を押す。

文字コード表は、キーボードにないUnicode文字を探してコピーする方法である。フォントを変えると表示される文字の種類も変わるため、貼り付け先で正しく表示できるフォントを選ぶ。

### 4. WordでUnicodeコードを変換する

Microsoft Wordでは、Unicodeの16進数コードを入力して `Alt` + `X` を押すと、対応する文字へ変換できる。

```text
2070 + Alt+X → ⁰
00B9 + Alt+X → ¹
00B2 + Alt+X → ²
00B3 + Alt+X → ³
2074 + Alt+X → ⁴
2075 + Alt+X → ⁵
2076 + Alt+X → ⁶
2077 + Alt+X → ⁷
2078 + Alt+X → ⁸
2079 + Alt+X → ⁹
```

手順は次のとおりである。

1. WordでUnicodeコードを入力する。
2. 入力したコードの直後にカーソルを置く。
3. `Alt` + `X` を押す。

この方法はWordなど対応するアプリで使える方法であり、すべてのWindowsアプリやブラウザーで動作するとは限らない。

### 5. Wordで任意の文字を上付きにする

「²」そのものを入力するのではなく、「10」の一部を上に寄せるなど、任意の文字列を上付き表示にする場合は書式設定を使う。

1. 上付きにしたい文字を選択する。
2. `Ctrl` + `Shift` + `+` を押す。

解除する場合は、同じショートカットをもう一度押す。リボンの「ホーム」タブにある上付き文字のボタン、またはフォント設定画面から変更することもできる。

### 使い分け

| 状況 | 推奨方法 |
| --- | --- |
| メモ帳、ブラウザー、チャットへ `²` や `³` を入力したい | 文字をコピーするか、記号パネルを使う |
| 多数の特殊文字から探したい | 文字コード表を使う |
| Wordで `²` などのUnicode文字をコードから入力したい | Unicodeコード + `Alt` + `X` |
| 任意の文字列を上付き表示にしたい | Wordの上付き書式 `Ctrl` + `Shift` + `+` |
