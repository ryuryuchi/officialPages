# Wordの表で指定セルだけ幅を調整する方法

## 概要

Microsoft Wordの表で、列全体ではなく指定したセルだけを対象に幅を調整する
操作方法、セル幅が連動する理由、および旧形式の `.doc` ファイルを編集する際の
注意点を整理する。

## 結論

通常の表では、同じ列にあるセルは同じ縦罫線（列境界）を共有する。そのため、
セル境界をドラッグして幅を変えると、同じ列の他セルも一緒に動くのは正常な動作で
ある。**［セル］→［優先幅］** はセルの希望幅を指定できるが、共有された列境界を
独立した境界にはしない。

幅を指定しても別セルが動く、または入力後に幅が戻る場合は、まず**表全体の
自動サイズ変更**を解除する。表を選択して **［表のプロパティ］→［表］→
［オプション］→［自動的に内容に合わせて表のサイズを変更する］** をオフにし、
続けて **［テーブル レイアウト］→［自動調整］→［固定列幅］** を選択する。
これでも共有される境界の連動自体は止められない。

特定の行だけで幅の異なる区画が必要なら、細かい列に**セルを分割**してから、不要な
区画を他の行で**結合**し、必要な境界だけを作る。見た目だけ余白を増減したい場合は
セル幅ではなく**セルの余白**を変更する。表の外枠を変えずに、そのセル内だけを
独立した区画にしたい場合は、セル内に入れ子の表を置く。`.doc` を編集する場合は、
元ファイルを保持したうえで `.docx` のコピーへ変換してから構造を変更することを
推奨する。

## 詳細

### 最初に行う切り分けと固定手順

Wordの表は、縦方向に続く罫線を列境界として共有する。あるセルの左右境界を
ドラッグすると、その境界を使う列幅が変わるため、同じ列のセルにも影響する。
これは、セルを1つだけ選択して操作していても同じである。

Microsoftの現行サポートは、セル単位の［優先幅］と列単位の幅を区別しているが、
セルの［優先幅］が共有境界を独立させるとは説明していない。このため、他行と異なる
区画を確実に作る場合は、分割・結合、入れ子表、または別表という構造上の方法を使う。

「入力した文字に合わせて戻る」「列幅を指定した直後に別の列が縮む」場合は、
次の順で設定する。これは内容に合わせて表や列の幅を再計算する機能を止める手順で
あり、共有境界を独立させる手順ではない。

1. 表内をクリックし、左上の表選択ハンドルを選択して**表全体**を選択する。
2. **［テーブル レイアウト］→［自動調整］→［固定列幅］** を選択する。
3. 表を右クリックして **［表のプロパティ］→［表］→［オプション］** を開く。
4. **［自動的に内容に合わせて表のサイズを変更する］** がオンならオフにして
   **［OK］** を選択する。
5. **［表］** タブで **［幅を指定する］** をオンにし、単位を **cm** または
   **インチ** にして表全体の幅を固定する。ページ幅に追従させたい場合を除き、
   パーセンテージは使わない。
6. 表をいったん保存し、別のセルをクリックしてから戻り、幅が維持されるか確認する。

5で表全体の幅を固定すると、ある列を広げたときに表の右端を広げる余地がない限り、
他の列が狭くなることがある。これは表の合計幅を守るための動作である。目的別に
次の方法を選ぶ。

| 目的 | 操作 | 影響範囲 |
| --- | --- | --- |
| 列全体の幅を変える | 列境界をドラッグ、または **［表のプロパティ］→［列］→［幅の指定］** | その列の全セル |
| 表の幅を維持して列の比率を変える | 固定列幅にした後、広げる列と狭める列を明示して数値指定する | 表内の列全体 |
| 特定行だけを複数の幅に分ける | 対象セルを選択し、**［テーブル レイアウト］→［セルの分割］**。不要な区切りは他行で **［セルの結合］** | 対象行の表構造 |
| 外側のセル幅を変えず、セル内だけを区画化する | 対象セル内に表を挿入し、その入れ子の表を固定列幅にする | 対象セルの内部 |
| セル内の文字と罫線の間隔を変える | **［テーブル レイアウト］→［セルの余白］**、または **［表のプロパティ］→［セル］→［オプション］** | 対象セルまたは表の設定 |
| 内容に応じて幅が戻るのを止める | 固定列幅を選び、［表のプロパティ］→［表］→［オプション］の自動サイズ変更もオフにする | 表全体 |

分割・結合後も、同じ縦罫線を共有するセルは連動する。複雑なレイアウトで各行の
区画を完全に独立させる必要がある場合は、別々の表を縦に配置する方法もある。

### 「一つのセルだけ」の意味別の確実な方法

実際の外枠を一つだけ動かしたい場合、同じ罫線を共有するセルがある限り、既存の表の
ままでは不可能である。次のいずれかへ構造を変更する。

1. **行ごとの区画を変えたい:** 最小単位になるまで対象行のセルを分割する。
   他の行では、不要になった隣接セルを結合する。これにより、変更対象の罫線を
   他行と共有しない構造にできる。
2. **セルの中にラベル欄・入力欄などを作りたい:** 外側のセルは変更せず、その中に
   1行または複数行の表を挿入する。入れ子の表は外側の表とは別のグリッドなので、
   内側の列幅を変えても外側の別セルは動かない。
3. **行ごとに完全に別の横幅が必要:** 表を行のまとまりごとに分けて縦に並べる。
   各表の［表のプロパティ］で同じ表幅と配置を数値指定し、表の間の段落前後を
   0 pt にする。

入れ子の表や別表は、罫線が二重に見えないよう、外側または内側の不要な罫線を
［罫線］で「なし」にする。アクセシビリティ上、見出しとデータの対応が必要な
表では、構造を複雑にしすぎず、見出しセルを明確にする。

### 数値で希望幅を指定する手順

1. 幅を変えたいセルの中をクリックする。
2. セル内を右クリックし、**［表のプロパティ］** を選択する。
3. **［セル］** タブを開く。
4. **［優先幅］** にチェックを入れる。
5. 希望する幅を入力し、必要に応じて測定単位を選ぶ。
6. **［OK］** を選択する。

［セル］タブの［優先幅］は選択セルに設定する。ただし、同じ列境界を持つ通常の
セルで、他セルへ影響しないことを保証する設定ではない。列全体の幅を数値で設定
したい場合は、［列］タブの［幅の指定］を使用する。

### マウスで調整する場合

対象セルを選び、ルーラー上のセル境界マーカーをドラッグして幅を調整できる。
`Alt` キーを押しながらドラッグすると、ルーラー上に寸法が表示される。
ただし、ドラッグするのは共有されうる列境界であるため、特定のセルだけの区画を
作る用途には、先にセルを分割・結合して必要な境界を作る。

### `.doc` ファイルを編集する場合

`.doc` は旧式のWordバイナリ形式であり、現在のWordで開くと通常は
**互換モード**で編集する。表の基本的な編集はできるが、旧形式で保存し続けると
新しいWord機能や書式が十分に保持されないことがある。

表を分割・結合するなど構造を変更する前は、次の手順で元ファイルを保護する。

1. 元の `.doc` ファイルを複製してバックアップを作る。
2. コピーをWordで開く。
3. **［ファイル］→［名前を付けて保存］** で、ファイルの種類に
   **［Word 文書（*.docx）］** を選び、別名で保存する。
4. 保存した `.docx` で表を編集する。
5. 受け渡し先が `.doc` を必須とする場合だけ、相手側のWordバージョンと
   レイアウトを確認したうえで `.doc` のコピーを書き出す。

元の `.doc` を上書き変換しないことで、変換後に罫線、改ページ、列幅などの
レイアウトに問題があった場合も元に戻せる。

### 注意点

- **［固定列幅］** と［自動的に内容に合わせて表のサイズを変更する］のオフは、
  指定セルだけでなく、選択した表に対する設定である。
- ［セル］タブの［優先幅］は「絶対幅」ではなく希望値であり、表全体の優先幅、
  自動調整、共有境界との間で再計算されうる。
- ページ幅に対する表の優先幅をパーセンテージで指定すると、余白、段組み、用紙方向
  の変更に伴って幅が変わる。幅を一定にしたい表では固定単位を使う。
- セルを分割・結合すると、セル内の文字列、罫線、結合前の内容の配置を確認する。
- 表を別々に分ける場合は、各表の幅、配置、段落前後の間隔をそろえると見た目を
  維持しやすい。
- Word for the webなど、利用環境によってはデスクトップ版と操作項目が異なる
  場合がある。
