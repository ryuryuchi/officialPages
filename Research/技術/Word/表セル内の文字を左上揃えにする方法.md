# Wordの表セル内の文字を左上揃えにする方法

## 概要

Microsoft Wordの表で、セル内の文字を左上に配置する操作と、配置が意図どおりに
見えないときの確認箇所を整理する。

## 結論

対象セルを選択して **［テーブル レイアウト］タブ→［配置］グループ→［左上揃え］**
を選び、さらに **［テーブル レイアウト］→［セルの余白］** で上下左右の余白を
最小値（必要なら 0）に設定する。段落前後の間隔とインデントも 0 にすると、文字を
枠線のキワまで詰められる。

この操作は、横方向の左揃えと縦方向の上揃えを同時に設定する。［ホーム］タブの
［左揃え］だけでは横方向しか変更されないため、文字がセルの中央や下側に残る場合は
［左上揃え］を使用する。

## 詳細

### Windows版Wordでの手順

1. 左上揃えにするセル、複数セル、または表全体を選択する。
2. リボンに表示される **［テーブル レイアウト］** タブを開く。
3. **［配置］** グループの9分割アイコンから **［左上揃え］** を選択する。
4. **［セルの余白］** を開き、上、下、左、右の余白を小さくする。罫線に最も近づける
   場合は、各値を **0** にする。
5. 文字がまだ上下に離れる場合は、対象段落を選択して **［ホーム］→［段落］** の
   段落設定を開き、**［前］** と **［後］** の間隔を 0 pt、左／右インデントを 0 にする。

［セルの余白］が表示されない場合は、表を右クリックして **［表のプロパティ］→［セル］→
［オプション］** を開き、セル余白を設定する。表全体の既定の余白を使っている場合は、
［表の既定のセルの余白とセルの間隔］で設定する。

### キワまで詰める際の注意

- 余白を 0 にすると、文字が罫線に接して読みにくくなったり、罫線と重なって見えたりする。
  0.05～0.1 cm 程度を残すのは視認性を保つための実務上の目安であり、Microsoftの
  必須値ではない。
- セル内の段落には、削除できない段落記号が末尾に存在する。セルの高さを文字と完全に同じ
  高さにはできないことがあり、この場合は行の高さを固定せず、自動調整のままにする。
- セル内に先頭の空白、空行、改行があれば削除する。［ホーム］の **¶** で編集記号を表示
  すると確認できる。

表の中をクリックすると、表を操作するための［テーブル レイアウト］タブが表示される。
通常の［レイアウト］タブではない点に注意する。

### 配置できない、または余白が残る場合

- 文字が横方向だけ中央または右側にある場合は、［ホーム］タブの［左揃え］でも
  左揃えにできる。ただし、上下位置も上にするには［テーブル レイアウト］の
  ［左上揃え］を選ぶ。
- 文字が左上揃えでも罫線から離れて見える場合は、セルの余白が設定されている可能性が
  ある。［テーブル レイアウト］→［セルの余白］、または［表のプロパティ］→
  ［セル］→［オプション］で余白を確認する。
- 段落の先頭に空行、改行、または段落前の間隔があると、文字はセルの上端から下がって
  見える。編集記号を表示して不要な改行を削除し、［ホーム］→［段落］で
  ［前の間隔］も確認する。
