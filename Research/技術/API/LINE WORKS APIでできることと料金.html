LINE WORKS APIでできることと料金

概要

LINE WORKSと外部システムをAPIで連携すると何ができるか、無料で利用できる範囲、 料金以外に発生し得る制約を、2026-09-04時点の公式情報を中心に整理する。

結論

  • LINE WORKS APIは、Bot、ユーザー・組織、トーク以外にも、掲示板、カレンダー、

アンケート、タスク、Drive、メール、ワークフロー、監査などを操作するWeb APIである。

  • フリープランは0円で、30名まで、共有ストレージ5GB。公式の料金・機能比較では、

トーク、カレンダー、タスク、掲示板、アドレス帳、アンケートが利用できる。

  • 公式APIドキュメントにはフリープランのRate Limit（1 APIあたり60 requests/min）が

明記されているため、少なくとも一部APIを無料プランで利用できることは確認できる。 ただし、利用できるScope（権限）やサービスはプランごとに異なるため、使いたいAPIの Scope一覧を事前に確認する必要がある。

  • API呼び出し自体の従量課金は、確認した公式料金ページ・APIドキュメントには記載がない。

したがって「APIを呼ぶたびに別料金」とは確認できないが、契約プラン、外部サーバー、 データベース、監視などの連携側コストは別に発生し得る。

詳細

APIでできること

公式のAPIカテゴリを、用途が分かるようにまとめる。

APIカテゴリ できることの概要 代表的な用途
Bot メッセージ送信、メニュー設定、Bot管理 自動通知、FAQ、申請受付
Directory ユーザー、組織、グループの取得・更新 入社・異動・退社の反映
Contact 連絡先、連絡先タグの管理 顧客・担当者の整理
Board / Note 掲示板、投稿、コメント、組織・グループノートの管理 社内情報の投稿・検索
Calendar 予定やカレンダーの取得・作成・編集・削除 会議予約、予定の同期
Form / Task アンケート、タスク、タスクカテゴリーの管理 回収状況や進捗の自動化
Drive マイドライブ、共有ドライブ、組織・グループフォルダの管理 ファイル連携、保存
Mail メールの送信・閲覧・削除、フォルダ・フィルタの管理 定型メール、メール処理
Workflow 決裁文書、申請フォーマットなどの管理 申請・承認システム連携
Audit / Monitoring 監査データ、モニタリングデータの取得 管理・監査レポート
CXTalk / AiNote / PaperOn / Security 各サービスの履歴・ノート・ファイル・設定などの管理 周辺サービスとの統合

Botはテキストだけでなくボタンやスタンプなどのメッセージ形式にも対応し、 グループのトークルームへ参加させることもできる。APIの各操作には、必要な OAuth Scopeを付与したAccess Tokenが必要である。

料金と無料利用の範囲

項目 フリープラン 有償プランの主な扱い
利用料金 0円 スタンダード、アドバンストなど。公式料金ページの契約・表示条件を確認
ユーザー数 30名まで 制限なし
共有ストレージ 5GB スタンダード1TB、アドバンスト100TB（公式比較表）
API Rate Limit 1 APIあたり60 requests/min スタンダード・アドバンストは1 APIあたり240 requests/min
通話・画面共有 複数人は最大4名、最長60分 複数人は最大200名、時間制限なし
APIに関係する主な機能 トーク、カレンダー、タスク、掲示板、アドレス帳、アンケート アドバンストではメール、Driveなども利用可能
サポート・SLA なし あり

無料で始める場合の判断は、次のように分けるとよい。

  1. Bot通知や小規模なカレンダー・アンケート連携を試すだけなら、フリープランで

開発検証を始められる可能性が高い。

  1. 30名超、5GB超、メール・Drive、監査データの継続取得、より高いAPI呼び出し頻度が

必要なら、有償プランまたは対象サービスのプラン条件を確認する。

  1. 無料でも、Botを動かすサーバー、HTTPSのWebhook受信先、データベース、ログ保存、

通知基盤などを外部に用意する場合は、その費用が別途かかる。

利用時の制約と開発の流れ

確認項目 公式仕様・注意点
認証 Developer Consoleでアプリを設定し、認可サーバーからAccess Tokenを取得してAPIを呼び出す
権限 APIごとに必要なOAuth Scopeが異なる。必要最小限のScopeを設定する
Rate Limit ドメイン単位・API単位で適用。フリーは60 requests/min、超過時はHTTP 429
個別制限 トークルーム登録は10 requests/min、audit.read・monitoring.readは10 requests/minなど
同時接続 ドメイン全体で最大5スレッド。超過時はHTTP 429
長時間運転 30分以上連続して呼び出す場合は、Rate Limitの半分以下が目安
エラー対応 429時は直ちに連打せず、リセット後に再試行。キャッシュで不要な呼び出しを減らす

標準的な導入手順は、(1) Developer Consoleでアプリ・Bot・Scopeを設定、(2) 認証して Access Tokenを取得、(3) APIリファレンスで対象APIの入力・権限・レスポンスを確認、 (4) 外部システムから呼び出す、(5) 429や権限エラーを監視する、という流れになる。

料金についての読み方

上表の「API利用可能」は、公式ドキュメントがフリープランのRate Limitを定義している こと、およびAPI Scopeがサービス・プランで異なると説明していることから判断したもの。 すべてのカテゴリ・Scopeがフリープランで使えるという意味ではない。

また、公式料金ページの表示価格は税抜きであり、契約期間や購入形態によって表示が 変わる場合がある。導入判断時は、必要なAPIのScopeと最新の料金表を同時に確認する。
