# LINE WORKS AiNoteでできることと制限

## 概要

LINE WORKS AiNoteについて、会議記録・文字起こし・要約を中心に、できること、できないこと、プランにより変わる機能を公式情報で調査した。参照日は2026-09-09。

## 結論

- AiNoteは、録音または音声ファイルから会議記録を作り、文字起こし、話者分離、AI要約、社内共有、検索・確認を行うクラウド型のAI議事録作成ツールである。
- 基本的な録音・文字起こし・AI要約・ノート共有は、公式ガイド上は全プランで利用できる。ただし文字起こし時間とAI要約回数には契約プランごとの上限がある。
- 外部の誰でも見られる公開共有には使えない。共有先は同一ドメインの社内メンバーに限られる。また、管理者にノート作成を制限された利用者は、作成・編集・削除・ダウンロード・共有ができず、共有ノートの閲覧のみとなる。
- 高度な機能にはプラン制限がある。自作の要約テンプレートはチーム以上、自動話者認識はチーム／ビジネス／エンタープライズ、外部連携APIはエンタープライズが対象である。
- AIによる文字起こし・要約には誤認識や要約漏れの可能性がある。公式発表も自動話者認識の精度は発話状況・音質により変動し、30人を同時に正確に識別する保証ではないとしている。重要な議事録は人が原音と照合・修正する前提で使う。

## 詳細

### できること

| 分類 | できること | 条件・補足 |
| --- | --- | --- |
| 会議記録の作成 | ブラウザ版・モバイル版で音声またはWeb会議を録音し、ノートを作る | 全プラン。録音・アップロード時はネットワーク接続が必要 |
| 音声ファイルの文字起こし | 既存の録音ファイルをアップロードして文字起こしノートを作る | 公式紹介では m4a、mp3、wav などを例示。対応形式・ファイルサイズの完全な一覧は今回確認できなかった |
| Web会議の録音 | Zoom、Microsoft Teams、Google Meet、LINE WORKS、Webex と連携し、会議を録音・文字起こしする | 連携先の仕様変更対応中は一時利用不可となる場合がある。ZoomではホストがログインしていないとBotが参加できない場合がある |
| 文字起こし | 会話をテキスト化する | 日本語、英語、韓国語、中国語（簡体・繁体）の5言語。既にアップロード済みのノートでは対象言語を変更できない |
| 話者分離 | 発言を話者ごとに分けて記録する | 全プランの基本機能として紹介されている |
| 自動話者認識 | 社内アドレス帳のメンバーを発話者として自動識別し、発話者名を反映する | チーム／ビジネス／エンタープライズ。1会議で最大30人を識別対象にするが、正確な同時識別を保証するものではない |
| AI要約 | 全体要約、会議テーマ、タスク、段落ごとの主な内容を抽出する | 全プラン。要約を追加するたびに使用回数を消費する |
| 次のステップ | AI要約と併せて、会議内のToDoを一覧化する | ソロ／チーム／ビジネス／エンタープライズ |
| 要約の形式指定 | 自分用の要約テンプレートを作成・修正する | チーム／ビジネス／エンタープライズのみ。最大10個、タイトル50文字・指示2,000文字まで |
| 要点の記録・参照 | ブックマーク、ハイライト、メモを付け、該当時刻へ移動して原音を再生する | 全プラン。ハイライトをまとめて確認できるのはブラウザ版のみ |
| 社内共有 | ノートを同一ドメインのメンバーへ共有し、共有先へ通知する | 全プラン。共有リンクへのパスワード設定、直接共有、アクセス者・パスワード誤入力による制限の確認が可能 |
| 管理・削除 | 作成者はノートの編集・ダウンロード・削除を行える。ゴミ箱へ移動したノートは1年間は復元できる | ゴミ箱を空にする、または完全削除したノートは復元できない |
| 外部システム連携 | APIでノート一覧・詳細・内容の取得、特定ノートの削除、ドメイン／メンバー別の文字起こし時間・AI要約使用状況の照会を行う | エンタープライズのみ |

### できないこと・制約

| 項目 | できないこと・制約 | 影響・対処 |
| --- | --- | --- |
| 社外公開 | 共有リンクを知る社外ユーザーへ無制限に公開する用途には使えない | 共有先は同一ドメインの社内メンバーに限定される。社外共有が必要な場合の公式な可否・代替手段は今回確認できなかった |
| 権限制限された利用者 | ノートを新規作成、共有ノートを編集・削除・ダウンロード・共有できない | 管理者がノート作成を制限した場合。閲覧だけは可能 |
| 共有先の編集・出力 | 共有された側は編集・ダウンロードできない | 作成者が編集・ダウンロードする |
| 要約テンプレート | フリー／ソロでは自作テンプレートの作成・修正ができない | 標準テンプレートを使うか、チーム以上を検討する |
| 自動話者認識 | フリー／ソロでは利用できない | 話者分離や手動での参加者指定を使う |
| API | エンタープライズ以外では外部連携APIを利用できない | API連携が必須ならエンタープライズの契約条件を確認する |
| 文字起こし・要約の利用量 | 無制限ではない | 各プランに月間の文字起こし時間とAI要約回数の枠がある。企業向けの年額契約では、チームは月6,000分・要約120回、ビジネスは18,000分・360回、エンタープライズは60,000分・1,200回 |
| Web会議連携の可用性 | 外部サービス側の仕様変更などにより、一時的に録音できない場合がある | 公式の障害・案内を確認し、必要ならモバイル端末での録音からノートを作る |
| 精度 | 話者名・文字起こし・要約の完全な正確性は保証されない | 音質、発話の重なり、固有名詞を考慮し、重要な決定事項・氏名・数値は人が確認する |

### プランを選ぶ目安

| 要件 | 必要になる最低限の考え方 |
| --- | --- |
| 文字起こし、AI要約、社内共有を試す | 基本機能は全プランで利用可能。ただし利用量の上限を確認する |
| 会議ごとに決まった書式で要約したい | チーム以上（自作要約テンプレート） |
| 社内メンバー名を発言へ自動反映したい | チーム以上（自動話者認識） |
| ノートを自社システムと連携・自動取得したい | エンタープライズ（外部連携API） |
| 多人数・多会議で使いたい | 文字起こし時間とAI要約回数を基準に、チーム／ビジネス／エンタープライズを比較する |

### 今回は確認できなかったこと

- フリー／ソロプランの最新の月間文字起こし時間、AI要約回数、1回当たりの録音・アップロード上限、データ保管期間。
- 音声ファイルの対応形式、最大ファイルサイズ、最大時間の網羅的な公式仕様。
- 社外者へ安全に共有する公式機能または正式な代替手段。
- AI要約・文字起こしデータをAI学習に使用するかどうかの、全プラン共通かつ現行の公式規約上の扱い。

これらは契約・データ取扱いの判断に直結するため、導入前に公式の最新プラン表、利用規約、販売窓口へ確認する必要がある。
