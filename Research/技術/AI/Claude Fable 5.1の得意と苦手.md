# Claude Fable 5.1の得意と苦手

## 概要

Anthropicの現行モデル一覧に掲載されている最上位級モデル「Claude Fable 5.1」について、
得意なこと(強み)と苦手なこと(弱み・制約)を、公式ドキュメントと公式発表を
基に整理した。モデル選定や利用時の注意点の判断材料にすることが目的である。

## 結論

- Fable 5.1はAnthropicが長期間のエージェント作業向けに位置づけるモデルで、特に
  **長時間・長期間の自律エージェント作業**、**大規模コードベースでの
  ソフトウェアエンジニアリング**、**高度な知識労働(金融分析など)**、
  **ビジョン(画像理解)**、**長文脈とメモリ活用**に強い。
  タスクが長く複雑であるほど他モデルとの差が開く。
- 一方で、**応答が遅い**(現行ラインナップ中で最遅)、**価格が高い**
  (入力$10/出力$50 per MTok、Opus 5の2倍)、**安全クラシファイアによる
  拒否・フォールバック**(サイバーセキュリティ、生物・化学、蒸留関連。
  良性の依頼も誤検知あり)という明確な弱み・制約がある。
- 攻撃的サイバーセキュリティや生物・ライフサイエンスの作業は仕様として
  対象外である。現行のClaude製品では、分類されたサイバー依頼は原則Opus 4.8、
  生物関連依頼はOpus 5へフォールバックし、APIでは拒否または設定した代替モデルへ
  ルーティングされる。
- 簡単・高速・低コストが必要な用途にはSonnet 5やHaiku 4.5、拒否リスクを
  避けたいコーディング用途にはOpus 5が公式にも推奨されている。

## 詳細

### Fable 5.1とは

- Anthropicの現行モデル一覧では、難しい推論と長期間のエージェント作業向けの
  モデルとして掲載されている(モデルID: `claude-fable-5-1`)。
- Anthropicの公式一覧では、Fable 5.1とOpus 5は別モデルとして掲載されている。
- コンテキスト1Mトークン、最大出力128Kトークン、適応的思考(常時オン)、
  effortパラメータ対応(既定`high`)。知識カットオフは2026年6月。
- 2026年9月7日時点で現行一覧に掲載され、2027年9月1日より前に廃止しないと
  案内されている。

### 得意なこと(公式情報に基づく強み)

| 分野 | 内容 | 根拠・実例 |
| --- | --- | --- |
| 長時間の自律作業 | 数時間〜数日規模のゴール指向タスクを、指示を保持したまま完遂できる | 公式は「人が数時間〜数週間かかるend-to-end作業に特に有効」と明記 |
| ソフトウェアエンジニアリング | 大規模コードベースの移行・実装で先行モデルを大きく上回る | Stripeが5,000万行のRubyコードベースで、人手ならチームで2か月超の移行を1日で完了と報告。CognitionのFrontierCodeでフロンティアモデル中最高スコア(medium effortでも) |
| 一発正答性 | 明確に仕様が決まった複雑な問題を1回で正しく実装 | 早期テスターが「従来は数日の反復が必要だったシステムの単一パス実装」を報告 |
| 知識労働・分析 | 文書ベースの推論、図表の解釈、根本原因分析など | HebbiaのFinance Benchmarkで全モデル中最高スコア。IMCがトレーディング分析評価でほぼ全項目最高と報告 |
| ビジョン(画像理解) | 科学的図表からの数値抽出、スクリーンショットだけからのWebアプリ再構築など | 公式が「ビジョンの新SOTA」と明記。最小限のvision-onlyハーネスでポケモンFireRedをクリア |
| 長文脈・メモリ | 数百万トークン規模でも集中を維持し、自分のメモを活用して成果を改善 | Slay the Spire実験で、ファイルベースのメモリによる性能向上がOpus 4.8の3倍 |
| コードレビュー・デバッグ | バグ発見の再現率(recall)がOpus 4.8より顕著に向上 | 公式プロンプトガイドに明記(安全クラシファイア対象領域を除く) |
| 曖昧な依頼への対応 | 複雑で多岐にわたる依頼から次の手を自分で決められる | 公式プロンプトガイドに明記 |
| 並列サブエージェント管理 | サブエージェントの並列派遣と長期の連携管理が大幅に安定 | 公式プロンプトガイドに明記 |
| 指示遵守 | 短い指示で多くの挙動を制御できる水準に向上 | 公式プロンプトガイドに明記 |

### 苦手なこと・弱み・制約

| 分類 | 内容 | 補足 |
| --- | --- | --- |
| 速度 | 現行ラインナップで最も遅い(公式表記「Slower」)。高effortでは1リクエストが数分に及び、自律実行は数時間続くことがある | クライアントのタイムアウトや進捗表示の見直しが公式に推奨されている |
| 価格 | 入力$10/出力$50 per MTokで、Opus 5($5/$25)の2倍、Sonnet 5($2/$10)の5倍 | 単純・大量・低コスト用途には不向き |
| 安全クラシファイアによる拒否 | サイバーセキュリティ、生物・化学、蒸留(能力抽出)関連の依頼を検知すると代替モデルへフォールバックまたは拒否(`stop_reason: "refusal"`) | Claude製品の既定はサイバーがOpus 4.8、生物がOpus 5。良性依頼も誤検知され得る。公式は発売時に発動がセッションの5%未満とした |
| 対象外の用途 | 攻撃的サイバーセキュリティ、生物・ライフサイエンス作業は仕様として非対応 | これらが必要ならOpus 5などの他モデルを使う |
| 過剰な作業 | 高effortでは、依頼されていないリファクタリングや過剰な計画・検討をすることがある | 公式ガイドが抑制用のプロンプト文例を提供 |
| 早期停止 | 長いセッションの終盤で、ツール実行をせずに意図表明だけでターンを終えたり、不要な許可確認をすることが稀にある | 「continue」で再開可能。自律パイプラインには対策プロンプトが公式に用意されている |
| コンテキスト残量への過敏さ | 残トークン数が見えると、自発的に作業を切り上げたり新セッションを提案することが稀にある | 残量表示を見せない設計が公式に推奨される |
| 依頼外の行動 | 頼まれていないメール下書き作成やgitブランチのバックアップ作成など、余計な行動を取ることがある | 境界を明示するプロンプトで抑制 |
| 出力の読みにくさ | 長いエージェント作業後に、矢印記法などの省略的で読みにくい文章を書くことがある | 通信スタイル指示で緩和 |
| API仕様上の制約 | 思考の無効化は不可(常時オン)。生の思考過程は返らず、要約(summarized)か省略(omitted)のみ | 深さはeffortでのみ制御 |
| 知識の新しさ | 知識カットオフは2026年6月で、Opus 5(2026年5月)より新しい | 最新知識が必要な場合は注意 |
| データ保持 | 30日間のデータ保持が必須で、ゼロデータ保持(ZDR)は選択不可 | コンプライアンス要件によっては採用不可 |
| 供給の安定性 | 2026年6月12日〜7月1日に米政府の輸出規制で提供が一時停止された実績があり、サブスクリプションでの提供条件も変動している | 単一モデル依存を避け、フォールバック設計が現実的 |

### 事実と評価の区別

- 上記の表の内容は、Anthropicの公式ドキュメントおよび公式発表に記載された
  事実・自己報告に基づく。ベンチマークや顧客事例はAnthropic側の発表であり、
  第三者による独立検証を確認したものではない(推測を避けるためこの点を明記)。
- 「単一モデル依存を避ける」という記述は、公式のフォールバック機能の存在と
  提供停止の経緯から導いた本メモの判断である。

### 使い分けの目安(公式のモデル選定指針より)

| 必要なもの | 推奨モデル |
| --- | --- |
| 最高の能力(長時間エージェント、深い推論、高度な研究) | Fable 5 |
| 複雑なエージェント型コーディング、企業業務(拒否リスクなし) | Opus 5 |
| 速度と知能のバランス(コード生成、データ分析、コンテンツ作成) | Sonnet 5 |
| 最速・最安でニアフロンティア性能(リアルタイム、大量処理) | Haiku 4.5 |
