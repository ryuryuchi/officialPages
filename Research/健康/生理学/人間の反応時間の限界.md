# 人間の反応時間の限界

## 概要

光や音などの刺激を受けてから、ボタンを押す、走り出すといった動作を
開始するまでに、人間がどの程度の速さで反応できるかを調べた。

日常語の「反射神経」は、厳密には脊髄反射などの「反射」ではなく、
刺激を知覚して随意運動を起こすまでの「反応時間」を指すことが多い。
このメモでは、主に後者を扱う。

## 結論

- 健康な若年者の単純反応時間の代表値は、音に対して約160 ms、
  光に対して約190 msである。
- 一般的な目安として、単純な視覚反応は約180～250 ms、
  単純な聴覚反応は約150～200 msに収まることが多い。
- 訓練された人の非常に速い反応は約100～150 msの領域に入る。
- 100 msは便利な競技上の基準ではあるが、人間の生理学的な絶対下限ではない。
  実験では、短距離選手の単純聴覚反応に100 ms未満の例が確認されている。
- 刺激を見分けたり、複数の動作から選んだりする場合は判断処理が加わるため、
  反応時間は通常、単純反応より長くなる。

したがって、「意識して行う反応」の大体の限界は100 ms前後と表現できるが、
条件によっては100 msを下回り得る。一般的な成人の実用的な目安は、
単純反応で150～250 ms程度と考えるのが妥当である。

## 詳細

### 反応時間の種類

反応時間は、課題によって主に次のように分けられる。

- 単純反応時間:
  1種類の刺激に対し、決められた1種類の動作を行う。
- 識別反応時間:
  反応すべき刺激と、反応してはいけない刺激を見分ける。
- 選択反応時間:
  複数の刺激に応じて、異なる動作を選択する。

一般に、識別や選択が必要になるほど脳内の処理が増え、反応時間は長くなる。

### 数値の目安

| 条件 | 反応時間の目安 |
| --- | ---: |
| 単純な聴覚刺激 | 約150～200 ms |
| 単純な視覚刺激 | 約180～250 ms |
| 訓練された人の非常に速い単純反応 | 約100～150 ms |
| 識別や選択を伴う反応 | 約300～500 ms以上になることがある |

上記は測定方法や参加者によって変わる概算であり、個人の厳密な正常範囲を
定める数値ではない。年齢、疲労、注意、練習、運動習慣、刺激の強さなども
反応時間に影響する。

### 100 msは絶対的な限界か

短距離走では、World Athleticsの競技規則により、認証されたスタート情報システムが
0.100秒未満の反応時間をフライングの可能性として検知し、スターターが反応時間などを
確認する。この100 ms基準は現行規則でも維持されているが、人間が100 ms未満では
絶対に反応できないことを意味しない。

短距離選手9人を対象にした研究では、少なくとも1条件で平均反応時間が
100 ms未満となった選手が5人いた。また、最初の2条件における全スタートの
約20%で100 ms未満の反応が記録された。研究者は、単純聴覚反応の神経筋・
生理学的な部分が85 ms未満、筋電図上の潜時が60 ms未満になり得ると報告している。
2021年の批判的レビューも、100 msを一律の生理学的下限とみなす科学的根拠や、
測定システム間の差を論点としている。

このため、100 msは「通常は非常に速い反応」であることを示す実用的な目安
ではあるが、生理学的な絶対下限とは区別する必要がある。

### 測定時の注意

Webサイトやゲームで測定した値には、人間自身の反応時間以外に、次の遅延が
含まれる。

- ディスプレイの表示更新までの遅延
- マウスやキーボードの入力遅延
- OS、ブラウザ、測定プログラムによる遅延
- ネットワーク処理を使用する場合の遅延

したがって、家庭用機器による測定結果と、専用装置を使った研究結果を
そのまま比較することはできない。また、刺激が出る時刻を予測できる課題では、
純粋な反応ではなく予測によって値が短くなる場合がある。
