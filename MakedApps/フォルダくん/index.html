フォルダくん 取扱説明書

テンプレートを選ぶだけで、決まったフォルダ構成や初期ファイルをまとめて作成する Windows 用ツールです。

この取説を最初に読む人向け：最短手順
  1. フォルダくん.exe と template.json を同じフォルダに置く。
  2. フォルダくん.exe を起動する。
  3. 上部のテンプレートを選ぶ。
  4. 「作成先フォルダ選択」で作成先を選ぶ。
  5. 「フォルダ作成」を押し、プレビューで内容を確認する。
  6. 問題がなければ「実行」を押す。

右クリックから起動したい場合は、3. 右クリックメニューに登録するを設定してください。

注記

template.json はテンプレートの本体です。実行ファイルだけを別の場所へ移動するとテンプレートが表示されないため、必ず同じフォルダに置いてください。

1. できること

フォルダくんでは、次の内容をテンプレートとして登録できます。

  • 複数階層のフォルダを一括作成
  • 空のフォルダを含む定型フォルダ構成の作成
  • フォルダ作成時に初期ファイルも作成
  • テンプレートの追加、削除、並び替え
  • 既存フォルダ・既存ファイルを確認してから実行
  • 実行前プレビュー
  • 書き込みを行わないDry Run
  • エクスプローラーの右クリックメニューから作成先を指定して起動

用途の例

よくあるテンプレート例
用途作成される例
新規ツール00_Source、10_exe、20_文書、30_参考資料
資料作成原稿、画像、完成版、参考資料
プログラム学習source、tests、docs、data
メモ整理inbox、処理中、archive

2. まず使う

2.1 ファイルを配置する

配布済みの実行ファイルを使う場合は、次の2ファイルを同じフォルダに置きます。

フォルダくん/
├─ フォルダくん.exe
└─ template.json

このリポジトリに含まれる配布用ファイルを使う場合の例です。

10_exe/
├─ フォルダくん.exe
└─ template.json

ソースコードから起動する場合は、次のようにします。

00_Sorce/
├─ main.py
└─ template.json

2.2 起動する

フォルダくん.exe をダブルクリックします。

画面上部に template.json のテンプレート名が表示されます。テンプレートが複数ある場合は、コンボボックスから使用するものを選択してください。

ソースコードから起動する場合

Python 3 と Tkinter がインストールされた環境で、00_Sorce フォルダをカレントディレクトリにして実行します。

python .\main.py

Windowsでは、Pythonのインストール時に「Add Python to PATH」を有効にしておくと便利です。

2.3 作成先を選ぶ

  1. 「作成先フォルダ選択」をクリックします。
  2. フォルダ選択ダイアログで作成先を選びます。
  3. ウィンドウのタイトルに選択したパスが表示されることを確認します。

たとえば C:\Work\NewProject を選んだ場合、テンプレート内の相対パスは次のように作成されます。

C:\Work\NewProject\00_Source
C:\Work\NewProject\10_文書
C:\Work\NewProject\20_参考資料

2.4 作成前に確認する

「フォルダ作成」をクリックすると、作成プレビューが開きます。

表示意味
新規まだ存在しないため、新しく作成される
既存ファイル同じ場所にファイルがある
既存ディレクトリ同じ場所にフォルダがある
新規作成対象を作成する
スキップ対象を変更しない
上書き既存ファイルをテンプレートの内容で置き換える

行を選択して「新規作成」「スキップ」「上書き」を押すと、その行の動作を変更できます。フォルダに対する「上書き」は選択できません。

安全に実行するおすすめ手順
  1. まず「Dry Run」を押して、対象と動作だけを確認する。
  2. 既存ファイルがある行は「スキップ」のままにする。
  3. 内容を置き換えたいファイルだけ「上書き」に変更する。
  4. 最後に「実行」を押す。

2.5 Dry Runを使う

Dry Runは、実際のフォルダ・ファイルを作成せずに実行予定を表示します。

テンプレートのパスが正しいか確認したいときや、既存フォルダへ適用する前の確認に利用してください。

3. 右クリックメニューに登録する

右クリック登録を行うと、エクスプローラーでフォルダを開いている状態から、作成先を自動設定してフォルダくんを起動できます。

3.1 事前準備

まず、実行ファイルの絶対パスを確認します。例：

C:\Tools\フォルダくん\フォルダくん.exe

パスに空白や日本語が含まれていても動作しますが、コマンドでは必ず実行ファイルのパス全体を二重引用符で囲んでください。

警告

右クリック登録後に実行ファイルを移動すると、登録したコマンドが古いパスのままになります。移動した場合は、登録を削除してから再登録してください。

3.2 Windows 11の「フォルダの背景」に登録する（おすすめ）

この設定では、フォルダを開いた状態で背景を右クリックしたときに「フォルダくんで作成」が表示されます。%V が現在開いているフォルダのパスに置き換わります。

レジストリエディターで設定する

  1. Win + R を押します。
  2. regedit と入力してEnterを押します。
  3. ユーザーアカウント制御が表示されたら「はい」を押します。
  4. 次の場所へ移動します。 
    HKEY_CLASSES_ROOT\Directory\Background\shell
  5. shell を右クリックし、「新規」→「キー」を選びます。
  6. キー名を フォルダくん にします。
  7. 作成した フォルダくん キーを右クリックし、「新規」→「文字列値」を選びます。
  8. 値の名前を Icon にし、値のデータへ実行ファイルのパスを入力します。 
    C:\Tools\フォルダくん\フォルダくん.exe
  9. フォルダくん キーを右クリックし、「新規」→「キー」を選び、キー名を command にします。
  10. command の「既定」をダブルクリックし、次の形式で入力します。 
    "C:\Tools\フォルダくん\フォルダくん.exe" "%V"
  11. レジストリエディターを閉じます。
  12. エクスプローラーで任意のフォルダを開き、背景を右クリックします。
  13. Windows 11では「その他のオプションを表示」を開き、「フォルダくん」を選びます。

登録後の動作

たとえば C:\Work\ProjectA を開いて実行すると、フォルダくんの作成先が自動的に次のようになります。

C:\Work\ProjectA

毎回「作成先フォルダ選択」を押す必要はありません。

3.3 フォルダそのものの右クリックに登録する

フォルダを開かず、フォルダアイコンそのものを右クリックして起動したい場合は、次の場所に登録します。

HKEY_CLASSES_ROOT\Directory\shell

作成するキーの構成は次のとおりです。

HKEY_CLASSES_ROOT
└─ Directory
   └─ shell
      └─ フォルダくん
         └─ command

command の既定値は %1 を使います。

"C:\Tools\フォルダくん\フォルダくん.exe" "%1"

背景メニューとフォルダアイコンの両方に登録する場合は、Background\shell と Directory\shell の両方に同じ設定を作成してください。

3.4 .reg ファイルで登録する方法（任意）

レジストリエディターを手作業で操作する代わりに、次の内容を .reg ファイルとして保存して実行することもできます。

C:\\Tools\\フォルダくん\\フォルダくん.exe の部分は、自分の環境の実行ファイルパスに置き換えてください。レジストリファイル内では、区切り文字の \ を2つ書きます。

Windows Registry Editor Version 5.00

[HKEY_CLASSES_ROOT\Directory\Background\shell\FolderKun]
@="フォルダくんで作成"
"Icon"="C:\\Tools\\フォルダくん\\フォルダくん.exe"

[HKEY_CLASSES_ROOT\Directory\Background\shell\FolderKun\command]
@="\"C:\\Tools\\フォルダくん\\フォルダくん.exe\" \"%V\""

[HKEY_CLASSES_ROOT\Directory\shell\FolderKun]
@="フォルダくんで作成"
"Icon"="C:\\Tools\\フォルダくん\\フォルダくん.exe"

[HKEY_CLASSES_ROOT\Directory\shell\FolderKun\command]
@="\"C:\\Tools\\フォルダくん\\フォルダくん.exe\" \"%1\""

保存時の文字コードは、Windowsのレジストリエディターで読み込める形式にしてください。文字化けする場合は、メモ帳の「名前を付けて保存」でUTF-16 LEを指定して保存します。

登録を削除する方法
  1. Win + R → regedit を開きます。
  2. 背景メニューを削除する場合は、次のキーを削除します。 
    HKEY_CLASSES_ROOT\Directory\Background\shell\フォルダくん
  3. フォルダアイコンのメニューを削除する場合は、次のキーを削除します。 
    HKEY_CLASSES_ROOT\Directory\shell\フォルダくん

キーを削除する前に、対象キーを右クリックして「エクスポート」を選ぶとバックアップできます。

3.5 Windows 11で表示されない場合

Windows 11の新しい右クリックメニューでは、登録した項目が「その他のオプションを表示」の中に入る場合があります。

次を確認してください。

  • command のパスが実行ファイルの実際の場所と一致している
  • 実行ファイルのパス全体が二重引用符で囲まれている
  • 背景メニューは Directory\Background\shell に登録されている
  • フォルダアイコンメニューは Directory\shell に登録されている
  • エクスプローラーを再起動している
  • フォルダくん.exe と template.json が同じフォルダにある

エクスプローラーを再起動するには、タスクマネージャーで「Windows エクスプローラー」を選び、「再起動」を押します。

4. テンプレートを編集する

4.1 テンプレート編集画面を開く

  1. メイン画面の「テンプレート編集」を押します。
  2. 左側のテンプレート一覧から編集対象を選びます。
  3. 右側の「フォルダ」または「ファイル」タブを選びます。

4.2 フォルダを登録する

「フォルダ」タブでは、1行に1つの相対パスを入力します。

00_Source
10_exe
20_文書
20_文書\画像

/ で区切る書き方も利用できます。

00_Source
10_exe
20_文書
20_文書/画像

入力内容に応じて、上部のツリー表示が更新されます。ツリー上で同じ階層の項目をドラッグすると並び順を変更できます。

4.3 初期ファイルを登録する

「ファイル」タブの「追加」を押し、次の2項目を入力します。

項目例
ファイルパスdocs/README.md
初期内容# Project

ファイルの親フォルダは、実行時に自動作成されます。たとえば docs/README.md を登録すると、docs が存在しない場合でも作成されます。

ファイルの編集は、一覧の行を選択して「編集」を押すか、行をダブルクリックします。

4.4 テンプレートを追加・削除する

  • 「新規」：空のテンプレートを追加
  • 「削除」：左側で選択中のテンプレートを削除
  • 左側の ↑ / ↓：テンプレートの表示順を変更
  • 「保存」：template.json に書き込む

編集内容は「保存」を押すまでファイルへ反映されません。

警告

「削除」はテンプレート定義を削除する操作です。作成済みのフォルダやファイルは削除しません。

5. template.jsonを直接編集する

テンプレートはJSON形式で保存されています。文字コードはUTF-8を使用してください。

5.1 フォルダだけを作る形式

{
  "FolderTemplate": {
    "folders": [
      "00_Source",
      "10_文書",
      "20_参考資料"
    ]
  }
}

5.2 フォルダとファイルを作る形式

{
  "SampleTemplate": {
    "folders": [
      "source",
      "docs"
    ],
    "files": {
      "source/main.py": "# entry point\n",
      "docs/README.md": "# Documentation\n"
    }
  }
}

5.3 JSON記述ルール

項目の仕様
項目型内容
テンプレート名文字列メイン画面に表示する名前。重複不可
folders配列作成する相対フォルダパス
filesオブジェクトキーがファイルパス、値が初期内容
初期内容文字列UTF-8で書き込まれるテキスト

5.4 パスの制限

テンプレートのパスは、作成先の中に収まる相対パスだけを指定できます。

  • 絶対パスは指定できません（例：C:\temp、/tmp）
  • .. で作成先の外へ移動するパスは指定できません
  • Windowsで使用できない文字 < > : " | ? * は指定できません
  • 空のパスは指定できません
  • パス区切りは / が扱いやすく、\ も利用できます

入力が不正な場合は、作成前に「パスエラー」として表示され、作成処理は実行されません。

5.5 編集後に読み込ませる

外部エディターで template.json を編集した場合は、いったんフォルダくんを終了してから再起動してください。起動時に実行ファイルと同じフォルダの template.json が読み込まれます。

6. 作成時の動作

6.1 既存フォルダ

既に同じフォルダが存在する場合、初期状態では「スキップ」になります。既存フォルダそのものを削除したり、内容を消したりはしません。

6.2 既存ファイル

既に同じファイルがある場合、初期状態では「スキップ」になります。

  • 「スキップ」：既存ファイルを変更しない
  • 「上書き」：テンプレートの初期内容で置き換える

上書きする場合は、重要なファイルをバックアップしてから実行してください。

6.3 ファイルとフォルダが衝突する場合

同じパスにファイルとフォルダが混在するなど、作成できない構成はエラーになります。テンプレートの「フォルダ」タブと「ファイル」タブで、パスが重複していないか確認してください。

6.4 右クリック起動時の作成先

起動時にフォルダパスが引数として渡された場合、最初の有効なフォルダを作成先として使用します。

起動方法渡される値作成先
フォルダの背景メニュー%V開いているフォルダ
フォルダアイコンのメニュー%1選択したフォルダ
ダブルクリックなし起動時のカレントフォルダ
「作成先フォルダ選択」選択したパス選択したフォルダ

7. 困ったとき

テンプレートが表示されない
  • template.json が実行ファイルと同じフォルダにあるか確認する
  • ファイル名が template.json になっているか確認する
  • JSONのカンマ、括弧、引用符が正しいか確認する
  • 外部エディターで保存した場合は、フォルダくんを再起動する
  • 読み込みエラーが表示された場合は、エラーメッセージを確認する
右クリックから起動できない
  • command の実行ファイルパスを確認する
  • パスを二重引用符で囲む
  • 背景メニューなら %V、フォルダアイコンなら %1 を使う
  • Windows 11の「その他のオプションを表示」を確認する
  • 実行ファイルと template.json を同じフォルダに置く
  • レジストリ登録後にエクスプローラーを再起動する
ファイルが作成されない
  • プレビューで対象が「スキップ」になっていないか確認する
  • 同じ場所にフォルダが存在していないか確認する
  • 作成先への書き込み権限があるか確認する
  • パスに禁止文字や絶対パスが含まれていないか確認する
  • 必要なファイルだけ「上書き」に変更する
文字化けする

テンプレートファイルと初期ファイルはUTF-8で保存してください。.reg ファイルを読み込むときだけは、文字コードの影響でレジストリの表示名が文字化けする場合があります。その場合は、.reg ファイルをUTF-16 LEで保存してから再実行してください。

8. 開発者向け情報

8.1 リポジトリ構成

フォルダくん/
├─ 00_Sorce/
│  ├─ main.py
│  └─ template.json
├─ 10_exe/
│  ├─ フォルダくん.exe
│  └─ template.json
└─ 20_文書/
   ├─ 説明書.txt
   └─ フォルダくん_取扱説明書.md

8.2 テンプレートの読み込み場所

アプリは実行形式に応じて、次の場所から template.json を読み込みます。

  • .exe：フォルダくん.exe と同じフォルダ
  • Python実行：main.py と同じフォルダ

8.3 ビルド時の注意

PyInstallerなどで実行ファイルを作り直す場合でも、template.json は実行ファイルの横に配置してください。テンプレートを実行ファイルへ埋め込む方式ではないため、テンプレートを変更するたびに再ビルドする必要はありません。
