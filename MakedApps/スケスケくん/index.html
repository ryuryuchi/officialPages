1. スケスケくんとは

スケスケくんは、仕事や予定をローカルで管理するための デスクトップアプリケーションです。タスクをカンバンで 状態別に整理し、開始日と終了日を設定したタスクは ガントチャートで期間を確認できます。

タスクの登録・編集・削除や並び替えは、操作直後に 自動保存されます。通常の操作で「保存」ボタンを 押す必要はありません。

  • データは端末内の SQLite に保存されます。
  • カンバンとガントチャートをタブで切り替えられます。
  • JSON または CSV でバックアップ・移行できます。
  • 起動中は Windows のリマインダー通知を利用できます。

2. 起動する

必要な環境

  • Python 3.11 以上
  • PySide6
  • Windows（デスクトップ通知を使う場合）

開発環境から起動する

PowerShell でソースの 00_Source フォルダーへ 移動し、次のコマンドを実行します。 

python -m pip install -e .
python main.py

起動直後は「カンバン」タブが表示されます。アプリケーションを 終了しても、保存済みのタスクは次回起動時に読み込まれます。

3. 画面構成

場所 できること
タスク登録 新しいタスクを作成します。
JSON出力 / CSV出力 タスクをファイルへ書き出します。
JSON取込 / CSV取込 ファイルのタスクを現在のデータへ取り込みます。
通知設定 リマインダー通知とチェック間隔を設定します。
カンバン ステータス別にタスクを管理します。
ガントチャート 日付が設定されたタスクを期間で確認します。
プロジェクト作成 プロジェクトの作成・改名・削除を行います。

4. タスクを登録・編集する

新規登録

  1. 画面上部の「タスク登録」をクリックします。
  2. 必要な項目を入力し、「OK」をクリックします。
  3. 登録したタスクは、選択したステータスの列に表示されます。

カンバンの各列にあるカードのない場所をダブルクリックしても、 その列を初期ステータスにした登録画面を開けます。

入力項目

項目 入力方法・注意点
タイトル 必須項目です。空欄や空白だけでは登録できません。
開始日 / 終了日 カレンダーから選択します。「クリア」で未設定に戻せます。 表示・保存形式は yyyy-MM-dd です。
説明 タスクの詳細やメモを入力します。
ステータス アイデア、未着手、進行中、保留、完了から選びます。
優先度 なし、低、中、高から選びます。
進捗率 0〜100%の整数で入力します。
プロジェクト 既存のプロジェクトを選ぶか、新しい名前を入力します。
タグ 複数指定するときはセミコロン（;）で区切ります。

日付の入力

開始日と終了日を両方設定する場合、終了日は開始日以降にしてください。 日付の関係が正しくない場合は保存されず、入力エラーが表示されます。 未設定の日付でカレンダーを開くと、現在の月が表示されます。

編集・削除

カードの「編集」をクリックすると登録済みの内容を変更できます。 カードの「削除」をクリックすると確認ダイアログが開きます。 削除を実行する場合だけ「削除」を選び、残す場合は「キャンセル」を 選んでください。

5. カンバンで管理する

ステータス列

タスクは次の5列で管理します。

  1. アイデア
  2. 未着手
  3. 進行中
  4. 保留
  5. 完了

列を移動する

タスクカードをドラッグし、移動先の列へドロップします。同じ列の カードをドラッグして、列内の順番を変更することもできます。 どちらの変更も自動保存されます。

移動先 進捗率 完了日
アイデア 維持 消去
未着手 0% 消去
進行中 / 保留 維持 消去
完了 100% 移動日を記録

完了列から別の列へ移動すると、完了日は消去されます。カードを ダブルクリックすると、そのタスクの編集画面を開けます。

絞り込む

カンバン上部の絞り込み欄では、プロジェクト、タグ、優先度、 期限超過、完了日を組み合わせて表示対象を絞り込めます。 タグを複数選んだ場合は、いずれかのタグに一致するタスクが表示されます。

カードの見かた

表示 意味
青〜緑の枠線 進捗率を表します。進捗が高いほど緑に近づきます。
優先度の色 なしはグレー、低は青、中は黄、高は赤です。
赤系の背景 終了日を過ぎていて、まだ完了していないタスクです。

6. ガントチャートを使う

「ガントチャート」タブでは、開始日と終了日の両方が設定された タスクを期間バーで表示します。タスクはプロジェクトごとに グループ化され、プロジェクト未所属のタスクは「未所属」に まとめられます。

期間を変更する

  • バーの中央をドラッグすると、開始日と終了日をまとめて移動します。
  • バーの左端をドラッグすると、開始日だけを変更します。
  • バーの右端をドラッグすると、終了日だけを変更します。

日付の変更は1日単位で行われ、ドロップした時点で自動保存されます。 過去の日付は時間軸の背景が暗く表示されます。横スクロールで 過去・未来の期間を確認できます。

期間が表示されないタスク

開始日または終了日が未設定のタスクは期間バーになりません。 ガントチャートの下にある「未設定タスク」で件数とタスク名を 確認し、必要に応じてタスクを編集してください。

7. プロジェクトを管理する

  1. 「プロジェクト作成」タブを開きます。
  2. 入力欄に名前を入力して「作成」をクリックします。
  3. 一覧からプロジェクトを選び、名前を変更して「改名」をクリックします。
  4. 不要なプロジェクトを選び、「削除」をクリックします。

プロジェクト名は必須で、空白だけの名前は登録できません。タスクが 所属しているプロジェクトは削除できません。先にタスクのプロジェクトを 変更してから削除してください。改名・削除も自動保存されます。

8. データをバックアップ・移行する

エクスポート

画面上部の「JSON出力」または「CSV出力」をクリックし、保存先を選択します。

形式 おすすめの用途 特徴
JSON バックアップ・復元 形式バージョンとタスク配列を含みます。
CSV 表計算ソフトでの確認・加工 タグはセミコロン区切りで1セルに出力されます。

日付はどちらの形式でも YYYY-MM-DD で出力されます。 v1.1.1では、リマインダーの有効状態・通知対象・通知時刻も出力されます。

インポート

  1. 「JSON取込」または「CSV取込」をクリックし、ファイルを選択します。
  2. 既存タスクと同じIDがある場合は、重複候補の一覧を確認します。
  3. タスクごとに「追加」「上書き」「スキップ」を選びます。
  4. 「OK」をクリックして取り込みます。

重複判定はタイトルではなく一意IDで行われます。日付、ステータス、 優先度、進捗率などの形式が不正なファイルは取り込めません。 取り込み前に、念のため現在のデータをJSON出力しておくと安心です。

9. リマインダー通知を使う

タスクごとの設定

  1. タスクの登録・編集画面で「リマインダーを有効にする」をオンにします。
  2. 通知対象を「開始日」または「終了日」から選びます。
  3. 通知時刻を HH:mm 形式で設定します。
  4. 開始日または終了日が設定されていることを確認し、「OK」をクリックします。

通知対象日が未設定のままでは保存できません。完了済みタスク、 リマインダーを無効にしたタスク、対象日が未設定のタスクには通知されません。

アプリケーション全体の設定

画面上部の「通知設定」から、リマインダー通知の有効・無効と 定期チェック間隔（10〜3600秒）を変更できます。初期値は有効、 60秒です。設定は次回起動時にも引き継がれます。

通知はアプリケーション起動中に確認されます。アプリケーションを 終了している間の常駐通知には対応していません。同じタスク・同じ 通知設定への通知は一度だけ表示されます。

10. 保存とバックアップ

タスクやプロジェクトのデータは、OSのアプリケーションデータ領域 （Qtの AppDataLocation）に保存されます。具体的な場所は Windowsのユーザー環境によって異なります。

  • 普段の変更は操作直後に SQLite へ自動保存されます。
  • 別のPCへ移すときは、JSON出力したファイルを利用します。
  • 大切なデータは、アプリケーションを終了する前に定期的にJSON出力してください。

11. 困ったとき

通知が表示されない

  • 「通知設定」でアプリケーション全体の通知が有効か確認します。
  • タスクのリマインダー、通知対象日、通知時刻を確認します。
  • タスクが完了列になっていないか確認します。
  • Windowsの通知設定でアプリケーションの通知が許可されているか確認します。
  • アプリケーションが起動中であることを確認します。

ガントチャートにタスクがない

開始日と終了日の両方が必要です。ガントチャート下部の「未設定タスク」 で対象を確認し、タスク編集画面から日付を設定してください。

ファイルを取り込めない

JSONまたはCSVの形式と、日付・進捗率などの値を確認してください。 既存IDのタスクは、重複確認画面で「上書き」または「スキップ」を 選んでください。

プロジェクトを削除できない

タスクが所属しているプロジェクトは削除できません。タスクを編集して 所属を外すか、別のプロジェクトへ移してから削除してください。

12. まず覚える操作

  1. タスクを登録し、必要なら開始日・終了日をカレンダーで設定する。
  2. カードをドラッグして、作業の状態に合わせて列を移動する。
  3. 期間を確認したいタスクには、開始日と終了日を設定する。
  4. 定期的にJSON出力して、バックアップを作成する。
